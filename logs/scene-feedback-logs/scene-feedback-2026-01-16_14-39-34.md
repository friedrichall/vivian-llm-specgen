### 6) Functional Logic (Runtime States)

#### 6.1 Toaster State Machine
- **Idle**
  - Lever up
  - LED off
  - Resistors off
- **Toasting**
  - Starts when Lever is pressed to latched position
  - Duration derived from browning setting (configurable mapping)
  - LED on
  - Resistors on/glowing
- **Cancelled**
  - Triggered by StopButton during Toasting
  - Immediately transitions to Idle, lever returns up
- **Complete / Pop**
  - When timer ends
  - Lever returns up
  - Optional “pop” animation/sound (no measurements implied)
  - Returns to Idle

#### 6.2 Defrost Mode
- Toggle via `FunctionButton`
- Effects (configurable):
  - Extends toast time or alters heat curve
  - LED indicator could change color or blink (not defined in data; keep simple toggle)
